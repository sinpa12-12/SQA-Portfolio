## 🛠 기술 스택

- **언어:** Python (pytest, pywinauto)
- **도구:** GitHub Copilot, Atlassian Jira/Confluence, AIO Tests
- **AI 워크플로우:** GitHub Copilot + Atlassian MCP 연동
- **테스트 유형:** 블랙박스, 기능 테스트, GUI 자동화
